        開站設定

        第一次啟用帳號功能時，照著下面的步驟在網頁上完成即可，不需要登入伺服器改設定檔。前三步完成後才能開放註冊；Turnstile 建議也設定，用來擋機器人註冊。

          ✉️

          寄信（驗證信、重設密碼信）

          怎麼取得 Resend 金鑰？（約 10 分鐘）
          1. 到 resend.com 註冊（免費方案每月 3,000 封、每天 100 封）。
          2. 左側 Domains → Add Domain，輸入你的網域（例如 example.org）。
          3. Resend 會列出幾筆 DNS 記錄（DKIM 一筆，加上寄信用的 send、rsend 等記錄），到你管理網域的地方（例如 Cloudflare 的 DNS 頁）照抄新增，Cloudflare 的 Proxy 要選「DNS only」（灰雲）。Resend 只開寄信（Sending）的話沒有 MX，不用另外加。下方的「寄件網域 DNS」會告訴你哪幾筆已經生效。
          4. 左側 API Keys → Create API Key，權限選 Sending access，複製 re_ 開頭的金鑰貼到下面。金鑰只會顯示一次。
          5. 寄件 Email 填你網域底下的地址，例如 noreply@example.org（不需要真的有這個信箱）。
          寄件網域 DNS
          🛡️

          Turnstile 人機驗證

          怎麼取得 Turnstile 金鑰？（約 3 分鐘，免費）
          1. 登入 Cloudflare 後台，左側選 Turnstile → Add widget。網域不必放在 Cloudflare 也能用。
          2. Hostname 填 你的網域，Widget mode 選 Managed。
          3. 建立後複製 Site Key 和 Secret Key，貼到下面按「儲存並檢查」。
          4. 最後按「開始實測」親自通過一次，確認網域設定正確，訪客才不會卡在註冊畫面。
